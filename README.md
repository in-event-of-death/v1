# [Encrypted Messages for the Event of Death](https://in-event-of-death.github.io/v1/)

This project is designed to make sending encrypted messages to your loved ones in the event of your death easier. The encrypted messages can be entirely encrypted and decrypted using the [webpage](https://in-event-of-death.github.io/v1/), which can even be saved as a self-contained page for offline use.

This project uses [Shamir's Secret Sharing](https://en.wikipedia.org/wiki/Shamir%27s_Secret_Sharing) and [OpenPGP.js](https://openpgpjs.org/) to encrypt messages. This means that messages are encrypted in such a way that *multiple* encryption keys are required to decrypt them. This ensures that you do not have to trust a single individual with the ability to decrypt your messages.
